# Labour-to-Owner Salary Ledger
Streamlit app: daily salary movements by sector, occupation, qualification and company; labour vs owner value split; ML fair-pay check; government pay (7th CPC).

    pip install -r requirements.txt
    streamlit run app.py

Deploy: push this folder to GitHub, then create the app on Streamlit Community Cloud (main file: app.py).
Data is simulated until you add data/mca_companies.csv and a real wage feed (see the Method tab).
